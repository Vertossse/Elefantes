## Project Info
Proyecto en grupo de la asignatura de Análisis y Diseño de Aplicaciones (curso 26-27) de la Universidad de Málaga.
Este es un proyecto desarrollado siguiendo el Método del Caso que nos ha propuesto una empresa colaboradora (Turbineh) que actúa como el cliente, presentando su problemática el 29/09/2026. A partir de ahí, nuestro equipo realizará el análisis y diseño real de un sistema software para la creación, seguimiento y modificación de facturas de forma simple e intuitiva.
Adaptamos una metodología Scrum con sprints de aproximadamente 1-2 semanas, gestión de tareas con un tablero y control de versiones con Git. Cada entrega incluye su informe correspondiente realizado por el scrum master en esa entrega.
