# Elefantes

Proyecto en grupo de **Análisis y Diseño de Aplicaciones** (curso 2026-27) · Universidad de Málaga

## Sobre el proyecto

Proyecto desarrollado siguiendo el **Método del Caso**: la empresa colaboradora **Turbineh** actúa como cliente y presentó su problemática el 29/09/2026.

A partir de ahí, nuestro equipo realiza el **análisis y diseño** de un sistema software para la **creación, seguimiento y modificación de facturas** de forma simple e intuitiva.

## Metodología

- **Scrum** adaptado, con sprints de 1-2 semanas.
- Gestión de tareas mediante un **tablero** (backlog y sprint backlog).
- Control de versiones con **Git**.
- Cada entrega incluye su **informe Scrum**, redactado por el Scrum Master de ese periodo.
